# BUTION

Запуск одной GGUF-модели на нескольких компьютерах через `llama.cpp RPC`.

## Быстрый старт

### macOS

Откройте Terminal и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/danytebyya/bution/main/install.sh | bash
```

После установки откройте новое окно Terminal и запустите:

```bash
bution
```

С моделью:

```bash
bution --model "/полный/путь/model.gguf"
```

### Windows / HONOR

Откройте обычный PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/danytebyya/bution/main/install.ps1 | iex
```

Подтвердите стандартный запрос Windows на настройку Firewall. Затем откройте
новое окно PowerShell и запустите:

```powershell
bution
```

С моделью:

```powershell
bution --model "D:\Models\model.gguf"
```

Установщики сами:

- скачивают готовый BUTION;
- скачивают официальный `llama.cpp` с RPC;
- добавляют команду `bution` в PATH;
- на Windows создают Firewall-правила только для частной сети.

Rust, CMake, Visual Studio и самостоятельная сборка не нужны.

## Подключение Mac и HONOR

1. Подключите оба компьютера к одной Wi-Fi сети или hotspot телефона.
2. На HONOR запустите:

   ```powershell
   bution
   ```

3. На Mac запустите BUTION с GGUF-моделью:

   ```bash
   bution --model "/полный/путь/model.gguf"
   ```

4. Когда появится окно pairing, проверьте имя компьютера и выберите `Accept`.
5. Дождитесь завершения теста сети на экране `Benchmark`.
6. На Mac откройте `Cluster` и нажмите `Enter`.
7. После запуска модели перейдите в `Chat`.

GGUF достаточно хранить на основном компьютере. На worker копировать модель не
нужно — веса передаёт `llama.cpp RPC`.

Для проверки кластера выбирайте модель, которая не помещается в память одного
компьютера, но помещается в их суммарную доступную память. Для двух устройств по
16 GB обычно стоит начать с GGUF размером около 17–20 GB.

## Wi-Fi + Ethernet

Можно оставить Wi-Fi для интернета и соединить компьютеры Ethernet-кабелем.
BUTION проверит оба маршрута и выберет быстрый.

Если Ethernet не получил адрес автоматически:

- Mac: `192.168.50.1`, маска `255.255.255.0`;
- HONOR: `192.168.50.2`, маска `255.255.255.0`;
- gateway и DNS для Ethernet оставить пустыми.

## Управление

| Клавиши | Действие |
| --- | --- |
| `↑ ↓ ← →` | навигация |
| `Enter` | выбрать, запустить или остановить модель |
| `Esc` | назад |
| `Space` | переключатель |
| `Q` | выход и остановка процессов |
| `Ctrl+N` | новый чат |
| `Ctrl+L` | очистить чат |

## Обновление

Повторно выполните команду установки для своей системы. Она заменит BUTION и
`llama.cpp` актуальными версиями, не удаляя модели.

Единственное, что нужно скачать самостоятельно, — выбранная GGUF-модель: она не
включена в установщик из-за размера и разных лицензий моделей.

Если автоматический GitHub Release временно недоступен, macOS-установщик сам
соберёт BUTION. Для Windows рекомендуется повторить установку после завершения
публикации Release.
